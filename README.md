\# Network Security Policy Labs



A collection of cybersecurity practical labs focused on \*\*Network Security Policy Design and Implementation\*\* using Linux, Windows, Cisco Packet Tracer, and Python.



\## Overview



This repository contains 9 practical labs covering security policy implementation, system hardening, network protection, logging, auditing, VPN configuration, and automated security compliance checking.



These practicals are part of my cybersecurity learning journey, where I explore security configurations, implement policies, and verify their effectiveness in controlled lab environments.



\## Labs



| Lab | Practical |

|---|---|

| Lab 1 | Linux Password and Account Lockout Policy |

| Lab 2 | SSH Hardening |

| Lab 3 | Host Firewall with Default Deny |

| Lab 4 | Block Repeated Attackers with Fail2ban |

| Lab 5 | Cisco Device Hardening, Port Security, and ACLs |

| Lab 6 | Windows Password, Lockout, and Firewall Policy |

| Lab 7 | Logging and Auditing |

| Lab 8 | Remote Access with WireGuard VPN |

| Lab 9 | Automated Policy Compliance Checker in Python |

\## Learning Objectives



\- Implement password security and account lockout policies.

\- Harden SSH configurations and administrative access.

\- Configure host firewalls and access control lists.

\- Secure Cisco network devices.

\- Implement logging and auditing mechanisms.

\- Configure secure remote access using WireGuard VPN.

\- Automate security policy compliance checks using Python.

\- Verify security configurations through practical testing.

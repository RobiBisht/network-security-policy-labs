# Network Security Policy Design and Implementation

## Overview

This repository contains practical laboratory exercises completed as part of the subject **Network Security Policy Design and Implementation**.

The project focuses on implementing, configuring, and verifying security policies across Linux systems, Windows systems, network devices, and remote access environments.

## Objectives

- Implement password security and account lockout policies.
- Harden SSH remote administration.
- Configure host firewalls and default-deny rules.
- Protect systems against repeated authentication failures.
- Implement Cisco device hardening, port security, and ACLs.
- Configure Windows password, lockout, and firewall policies.
- Implement centralized logging and security auditing.
- Configure encrypted remote access using WireGuard VPN.
- Automate security policy compliance checks using Python.

## Security Notice

These configurations and scripts are intended for educational and authorized laboratory environments.

- Review configurations before applying them.
- Use isolated virtual machines where appropriate.
- Never commit passwords, private keys, or sensitive credentials.
- Back up configurations before making changes.
- Verify security controls after implementation.
